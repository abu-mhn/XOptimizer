What's New

Recent changes to X Optimizer.

Version v1.18.0

  • Which bey is up. The scoreboard now shows 1st, 2nd or 3rd Bey, and goes back to the 1st every new round.
  • Undo a wrong tap. Swipe down on a player's side to take back their last score. The points, bey and round all go back to how they were.
  • Faster, lighter. Profile pictures and banners are much smaller now and are remembered between pages, so lists open quicker and use far less data.
