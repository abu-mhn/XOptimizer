What's New

Recent changes to X Optimizer.

Version v1.13.0

  • Placings. Pick how many finishers a knockout decides — a Top 8 bracket can stop at 1st to 4th.
  • Reopen. Go back to registration after starting, change the format, then start again. Everyone stays registered.
  • Format on screen. A running tournament shows its format under the host name, with the join code for private rooms.
  • Removing a player. No longer redraws the tournament. Their opponent gets a free win and everything else stays put.
  • Paste order. Bulk-added names keep the order you pasted them — sort the list by "Added".
  • Bracket scrolling. The knockout no longer jumps back to the left every time you save a score.
  • Revox list. Renaming your account keeps your points on the same row, and everyone can now see members' photos and tags.
