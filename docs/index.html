What's New

Recent changes to X Optimizer.

Version v1.23.0

  • Tap Ready to start. Both players tap Ready before the scoreboard opens, so nobody is caught out by a match that has already begun.
  • 3, 2, 1, Go, Shoot. The countdown plays on screen, word by word, then the board appears.
  • Ready for every bey. Score a finish and it goes back to Ready for the next one, countdown and all. The score stays where it is — only the launch repeats.
  • Swap sides first. Sitting on the wrong side? Switch it from the Ready screen, before the match starts.
  • Turn your phone away and it starts over. Going back to portrait takes you to Ready again and clears the score, so a half-finished match never carries on by accident.
